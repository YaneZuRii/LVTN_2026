# Database (LTDD)

| File | Mô tả |
|------|--------|
| `thuvien_db.sql` | CSDL thư viện sách + bảng đăng nhập |
| `sach_get.php` / `sach_post.php` | API đọc/ghi sách |
| `dienthoai_db.sql` | CSDL danh sách điện thoại |
| `dienthoai_get.php` / `dienthoai_post.php` | API điện thoại |

Import `.sql` bằng phpMyAdmin (MySQL). Chạy PHP trên XAMPP/WAMP.

Nguồn: bài ôn LTDD, export phpMyAdmin localhost.
